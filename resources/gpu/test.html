GPU numeric experiment

This independent test evaluates emitted Clojure expression shaders in a real WebGL2 context, then reads numeric values back into JavaScript. It has no lighting output connection. Renderer details distinguish software contexts from unverified hardware.

Tests compare every component with saved values from the Clojure CPU evaluator. Timing includes upload, dispatch, asynchronous fence polling and readback; it is not an end-to-end show benchmark.

Ready. Default run: eight expression cases and 1,000/10,000 repeated fixture positions.
