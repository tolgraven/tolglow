# Linux dance-floor gateway

Keep this Lein project usable on a headless Linux host with BlueZ, independently of the full show. Reuse Tolglow’s OSC observation encoding and normal sensor admission. The application owns the ephemeral stage key, the D-Bus application and advertisement, and the optional UDP sender. Require explicit startup for each of them.

Maintain the wire contract shared with the Swift app, Watch and App Clip. Test the encrypted step/pulse and motion packet versions, the receiving-time energy/step accounting, shutdown and private D-Bus registration. Run `lein test` here and `lein with-profile +paired test` with the sibling Afterglow checkout. Keep raw sensor data, Bluetooth addresses, private session keys and pairing credentials out of logs and saved shows. Report physical radio qualification separately.
