# Embedded show host

The local Studio owns one Native Image isolate per foreground show. Open and close it on the same native thread. Keep the listener on an ephemeral loopback port and scoped credentials in Application Support. Selecting a folder grants access only while its show is running. Separate a generated or linked Mach-O from a successful local HTTP request, rendering the re-frame app, and running on physical hardware. Keep simulator and signed device artifacts distinct.
