# Full-app audience GPU sharing

Keep enrollment separate from motion participation. The Apple stage grants one QR-bound participant access after explicit consent and a live Bluetooth handshake. The App Clip and Watch participate in sensing. They do not ship a compute executable or qualify for grants.

The stage owns all host credentials, grant keys, time limits and link checks. Keep guest IDs pseudonymous. The host decides verification from the authenticated stage role. Use the shared production renderer and Transit job types in the phone bundle. Regenerate the resource with its pinned build script when the dispatcher changes.

Run the bundled shader proof and the paired OSC/Art-Net comparison, then compile the native targets and run the encrypted Mac loopback. Keep these measurements distinct from Apple-device radio throughput, WKWebView rendering, background/thermal exit and physical output qualification. See [operation and tests](README.md).
