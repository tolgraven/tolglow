# Local Studio

Each Mac window owns one local show process; `ShowRegistry` keeps one window per folder and gives devices and output to the first running show only (see docs/studio-ui.md, Windows and tabs). Views of a show are Studio tabs in one web view, not native tabs. A window binds its page to the runtime ID its show reports before loading it. The Ring host and re-frame client belong to the same release as the embedded GraalVM. Keep physical output and module startup in the operator's selected show configuration. A user opening that folder explicitly trusts its Clojure code.

Keep application source checkouts under Application Support. A release may install a new revision pair. Preserve existing worktrees and edits. Keep Java arguments as an array, choose an ephemeral loopback listener, and close the child's control pipe when the window quits. A failed start must leave the folder usable.

The Apple packaging workflow opens a real window and exercises the embedded runtime on Apple Silicon. Test signed distribution, actual AirPlay receivers and iOS background playback on their respective platforms.
