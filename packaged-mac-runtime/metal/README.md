It used the Studio JAR and resources from the [hosted ea993d3c package](https://github.com/tolgraven/tolglow/actions/runs/45290490338), the packaging repair from #515, and the native source and observer revision identified in `revisions.txt`. The served preview and worker were checked against the hosted source. The app tested the bundled JVM runtime.

The disconnected show started the Ember and Slow sweep cues before the window opened. The fragment programs for both the fog volume and depth-aware composite include `integrateFog` in the original GLSL and Metal standard library references in the translated source.

`summary.json` contains the bounded acceptance data. `receipt.json.gz` retains the observed programs and original GLSL and translated MSL for independent review. The loopback URL was removed.
