# tolglow

Add-ons and codebase for Afterglow stage light framework.

Track Tolglow and Afterglow work in [GitHub Issues](https://github.com/tolgraven/tolglow/issues). Issues carry each task’s scope, owner, evidence and remaining qualification. See the [source inventory](https://github.com/tolgraven/tolglow/issues/199) and [venue optics and fog](https://github.com/tolgraven/tolglow/issues/227) for examples.
