# Spatial controls in Studio and on Push

Open **Rig & space → Spatial controls**. Add a body, select its name and edit its fields. **Apply volume** submits the draft. Existing bindings keep using the same volume ID. A ball can have launch velocity, spin, restitution, hardness and attraction. A fixed attractor stays in place while another ball moves around it. The axes use metres and Y points up. **Room bounds and gravity** configures the limits of the simulation. **Modulate radius** on a ball or sphere accepts a shared signal, cue parameter, rhythmic random value, audio energy or waveform. Use the advanced volume definition to author a compound shape.

**Throw ball** starts a new trajectory from the authored position and velocity. **Throw in 3D** switches the rig editor to a throw gesture. Drag from the desired release point towards the destination on the selected plane. Drag distance and elapsed time set velocity in metres per second. Cancelling the gesture leaves the ball in its current trajectory. Choose the volume selection tool and touch a guide to edit it again. Ball, sphere, box and cylinder guides share the venue camera and their transformations update as the simulation runs. The body readout shows its current position, speed and fixture memberships.

Use **Contact actions** to aim moving heads, flicker or strobe the fixtures within a volume. Pick an existing effect, cue or a ranked random definition to launch on entry. Limit the action to a fixture set, group or intersecting volume. **On exit** follows the lifetime of the contact. A musical duration runs the action for the chosen number of beats, bars or phrases. Bindings continue to run while the editor is closed. With no other consumers, an unbound volume stops advancing when its last visible observer closes. **Keep running offscreen** keeps the simulation active.

The cue action menu and expanded active cue each offer **Launch on targets**. Search the names of patched fixtures, groups and volumes. Use the arrow keys and Enter, or tap a result. The show resolves the selected group or volume when it accepts the launch. Choosing **Orbit** on the surface therefore targets whichever fixtures are in Orbit at launch time.

On Push 2, open **Browse**, use the left/right page buttons if needed, and choose one of the eight visible targets with a top-row display button or a pad on the bottom row. The next cue press uses that selection once. **Cue defaults** clears a selection. The device display shows the upcoming target until the cue launches. Push 3 User Mode uses a captured button binding to the action `:target-picker`, the captured page-left/page-right buttons, and the bottom row of pads. This works in poly-aftertouch and configured MPE modes. Push 3 supplies display data to the external control view. Physical controls and on-device feedback still need verification on hardware.

The Studio uses an aggregate subscription for visible preview bodies and separate subscriptions for the selected body's details and members. Closing the view releases the subscriptions. Examples of durable show definitions, selector semantics, and scene event types are in the spatial show documentation.
